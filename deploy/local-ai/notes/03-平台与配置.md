# 平台与配置：哪项功能要注册哪个平台

来源：`docs/agents/deploying.md`「服务一览」+「申请和填写 key」+ `docs/configuration.md` + 代码逐行核对。所有变量以 `F:\eidolon-sc\.env.example`（316 行）为准。

## 总表

| 功能 | 平台 | 环境变量 | 大陆可用 | 可否本地化 |
|---|---|---|---|---|
| **文字聊天**（必填） | DeepSeek `platform.deepseek.com`（要充值）/ 硅基流动 / 阿里云百炼 / OpenAI / Anthropic / Gemini | `CHAT_LLM_BASE_URL`、`CHAT_LLM_API_KEY`、`CHAT_LLM_MODEL`，可选 `CHAT_LLM_PROTOCOL`（`chat-completions`/`responses`/`anthropic`） | DeepSeek/硅基/百炼直连 | ❌ 本次决定用 DeepSeek 云端 |
| **语音合成**（通话+朗读） | **只有** Fish Audio `fish.audio/app/api-keys` | `FISH_AUDIO_API_KEY`、`FISH_AUDIO_MODEL`（只能是 `s2.1-pro-free`/`s2.1-pro`/`drama-3`/`s2-pro`/`s1`，默认 `s2.1-pro-free` 不扣额度） | **要代理**（本机连不上 fish.audio） | ⚠️ 必须改码，见 `04-本地化调研.md` |
| **语音识别** | Soniox `console.soniox.com` 或 阿里云百炼 | `SONIOX_API_KEY`，或 `STT_PROVIDER=bailian` + `DASHSCOPE_API_KEY`（北京有免费额度，要实名 + 开通 `qwen-audio-3.1-asr-flash-streaming`） | 推荐百炼 | ⚠️ 必须改码 |
| **向量化** | 硅基流动 `cloud.siliconflow.cn` 或 Gemini | `SILICONFLOW_API_KEY`，或 `EMBEDDING_PROVIDER=gemini` + `GEMINI_API_KEY`（Gemini 不对大陆/港/澳开放） | 硅基直连 | ✅ **零改码**，见 `04` |
| **重排** | **只有**硅基流动 | `SILICONFLOW_API_KEY`（和向量化共用） | 直连 | ✅ **零改码** |
| **判断模型** | 三选一：阿里云百炼决策模型 / Cloudflare Workers AI / Jev 经 OpenRouter | `JUDGE_PROVIDER=jev\|cloudflare\|bailian`；`BAILIAN_JUDGE_API_KEY`+`BAILIAN_JUDGE_WORKSPACE_ID`+`BAILIAN_JUDGE_REGION`；或 `CLOUDFLARE_API_TOKEN`+`CLOUDFLARE_ACCOUNT_ID`；或 `JEV_API_KEY`（走 `openrouter.ai`，要代理） | 推荐百炼/Cloudflare | ✅ 靠 shim 可通，见 `04` |
| **生图（照片）** | NovelAI 或兼容中转 | `NOVELAI_API_KEY`、`NOVELAI_BASE_URL`、`NOVELAI_API_FORMAT`（`novelai`/`openai`） | 要代理 | ❌ 本机无 ComfyUI |
| **通话立绘** | 不用注册 | `EIDOLON_STAND_ASSETS_URL` + 存储桶（`EIDOLON_STAND_S3_*`） | — | 本机用 `http://localhost:8765` |
| **公网登录** | GitHub / Google OAuth（至少一家） | `GITHUB_CLIENT_*` / `GOOGLE_CLIENT_*`；本机用 `EIDOLON_DEV_LOGIN=1` | — | — |
| **素材/备份** | Cloudflare R2（推荐，不收流量费）或任意 S3 兼容桶 | `EIDOLON_STAND_S3_*`、`EIDOLON_BACKUP_S3_*` | — | — |
| 天气（制作人所在地） | 和风天气 | `QWEATHER_API_HOST/DEVELOPER_ID/PROJECT_ID/KEY_ID/PRIVATE_KEY`（五项要么全填要么全不填） | — | — |

其他：
- `BACKGROUND_LLM_*` 不填就沿用对话模型；**只填 `BACKGROUND_LLM_MODEL`** 就能在同一家换便宜模型
- `EIDOLON_PROXY_URL` + `EIDOLON_PROXY_SERVICES` 是后端访问外服唯一的代理配置（**不认 `HTTPS_PROXY`**；`HTTPS_PROXY` 只对 uv/npm/git/story sync/stand fetch 有用）
- 限额：`EIDOLON_TURNS_PER_HOUR`、`EIDOLON_CALLS_PER_HOUR`、`EIDOLON_PHOTOS_PER_HOUR`、`EIDOLON_READ_ALOUDS_PER_HOUR`、`EIDOLON_CALL_MINUTES`、`EIDOLON_TURNS_PER_CALL`、`EIDOLON_CONCURRENT_CALLS`
- 玩法开关：`EIDOLON_AFFINITY_AND_GIFTS`、`EIDOLON_SCHEDULE`、`EIDOLON_CYCLES`、`EIDOLON_BAR`、`EIDOLON_LETTERS`、`EIDOLON_MOMENTS`、`EIDOLON_REACH_OUTS`（后三个默认关）

## 必需性分四层（会话中给过的结论）

1. **硬必需**：`CHAT_LLM_*` —— 不填根本起不来（实测报错 `环境变量 CHAT_LLM_API_KEY未设置`）
2. **功能必需**：FISH（通话/朗读）、STT（通话）、SILICONFLOW（向量化/重排/检索/记忆）、judge（检索/记忆/好感度/照片/通话情绪）
3. **可选**：NovelAI（照片）、QWeather（天气）、OAuth（公网登录）、S3（素材/备份）
4. **不用配**：日程、周期、酒吧

## 可替代性 A/B/C 档

- **A 档（改环境变量即可）**：向量化、重排、生图（`base_url` 可覆盖）、judge 走 Jev 协议（`JEV_BASE_URL`）
- **B 档（加 provider 枚举，改码小）**：judge 换成本地 OpenAI 兼容、STT 加一家
- **C 档（锁死，必须重写客户端）**：TTS —— 全仓**没有** `FISH_AUDIO_BASE_URL`，地址硬编码在 `call.py:797`、`greetings.py:45`、pipecat `fish/tts.py:203`

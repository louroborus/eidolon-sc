## 1. 最小 `.env`（5 行，够跑文字对话）

放在 `F:\eidolon-sc\.env`：

```sh
CHAT_LLM_BASE_URL=https://api.deepseek.com/v1
CHAT_LLM_API_KEY=你的 DeepSeek key
CHAT_LLM_MODEL=deepseek-flash
EIDOLON_DEV_LOGIN=1
EIDOLON_SECRET_KEY=随便一串随机 hex（openssl rand -hex 32），填了就不要换
```

- DeepSeek 走 OpenAI 兼容的 Chat-Completions，`CHAT_LLM_PROTOCOL` 不用填（默认就是它）
- 后端启动时会发一次很小的检查请求，模型不支持流式 + 工具调用就拒绝启动
- `EIDOLON_SECRET_KEY` 不填也能跑，但不填就没法在后台保存 key（只影响后台）

想要记忆/检索/好感度，再加 `notes/03-平台与配置.md` 里的向量化/重排/判断模型三组。

## 2. 启动后端

```powershell
cd F:\eidolon-sc\backend
uv run --env-file=../.env eidolon serve
```

**三个必须知道的坑：**

1. **`--env-file` 是 uv 的参数，不是 eidolon 的。**
   `eidolon serve --env-file ../.env` → `eidolon: error: unrecognized arguments: --env-file`
   必须写成 `uv run --env-file=../.env eidolon serve`。

2. **必须在 `backend\` 目录下启动。** 配置里的默认路径全是相对路径：
   - `config.py:627` `EIDOLON_DATABASE_PATH` 默认 `data/eidolon.db`
   - `config.py:631` `EIDOLON_CHARACTERS_PATH` 默认 `../characters/characters.toml`
   - `config.py:636` 剧情 `../corpus/SCTranslationData/data/story`
   - `config.py:641` mirror `../corpus/mirror`
   - `config.py:666` 立绘构建 `../corpus/stand`

   在仓库根启动，`../characters` 会变成 `F:\characters`，直接找不到角色。

3. **端口由 `PORT` 决定**（`__main__.py:213` `int(os.environ.get("PORT", "8000"))`），默认 8000。

`backend/data/` 会被自动创建（`database.py:116` `path.parent.mkdir(parents=True, exist_ok=True)`），且 `backend/.gitignore:4` 有 `data/` → 不会污染 git。

**缺 key 时的报错很明确**（实测）：
```
✗ .env 有错，后端不会启动：环境变量 CHAT_LLM_API_KEY未设置
```
EXIT=1。启动早期还会打印 pipecat 1.12.0 的加载行，属正常。

## 3. 启动前端

```powershell
cd F:\eidolon-sc\frontend
$env:BACKEND_URL="http://localhost:8000"
npm run start
```

- `BACKEND_URL` 和 `EIDOLON_STAND_ASSETS_URL` 都是**运行时**读的（构建产物里是 `process.env.BACKEND_URL ?? "http://localhost:8000"`；`frontend/src/proxy.ts` 在运行时读 `EIDOLON_STAND_ASSETS_URL` 设 CSP）→ **现成的 `.next` 直接 `npm run start` 就行，不用重新 build**
- 开发模式才用 `npm run dev`

## 4. 停止

**不要指望 Ctrl+C 干净退出**：`next start` 的子进程会继续占着 3000。按端口杀：

```powershell
netstat -ano | findstr ":3000 "    # 拿 PID
Stop-Process -Id <PID> -Force
# 后端同理，找 :8000
```

`uv run` 在后端正跑着时可能因 `eidolon.exe` 被占而失败 → 加 `--no-sync`，或先停后端。

## 6. 开发登录（本机免 OAuth）

`EIDOLON_DEV_LOGIN=1` 时登录面板会多出「开发登录」，按名字直接登。等价接口：

```powershell
curl.exe -X POST http://localhost:8000/api/auth/dev-login `
  -H "Content-Type: application/json" -H "Origin: http://localhost:3000" `
  -d '{\"name\":\"Sallyn\"}'
```

⚠️ 配了 `EIDOLON_DOMAIN` 的公开部署检测到 `EIDOLON_DEV_LOGIN=1` 会**拒绝启动**（`Settings.__post_init__`）。

## 8. 语音通话的硬门槛

`FISH_AUDIO_API_KEY`（语音合成）+ `SONIOX_API_KEY`（语音识别，或 `STT_PROVIDER=bailian` + `DASHSCOPE_API_KEY`）两个都填才能通话，否则只有文字对话。

**fish.audio 在本机连不上**（见 `notes/01-本机环境.md` 网络表），要通话得配 `EIDOLON_PROXY_URL`：

```sh
EIDOLON_PROXY_URL=http://127.0.0.1:10808
EIDOLON_PROXY_SERVICES=judge,tts
```

注意后端**不认** `HTTPS_PROXY`（`proxy.py:48-50` 是 `trust_env=False`），只认 `EIDOLON_PROXY_URL` + `EIDOLON_PROXY_SERVICES`。
